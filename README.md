# Pibd-23_Zemskov_S.I._DrivingSchool

## Лабораторная работа №2 — автошкола

WinForms на .NET 8, PostgreSQL, EF Core 8 (Code First), Autofac и Serilog.

### Настройка и запуск

1. Откройте `DrivingSchool/DrivingSchool.slnx` и восстановите пакеты NuGet.
2. Подготовьте пустую базу `driving_school` в PostgreSQL. Приложение по умолчанию использует `127.0.0.1:5432` и пользователя `postgres`. Для других параметров задайте `DRIVINGSCHOOL_CONNECTION_STRING` в окружении запуска, используя `Passfile` вместо пароля в исходниках.
3. Для локальной настройки сохраните файл `%APPDATA%\DrivingSchool\pgpass.conf` в формате `127.0.0.1:5432:driving_school:postgres:ПАРОЛЬ`. Символы `:` и `\` в пароле экранируются как `\:` и `\\`. Файл находится вне репозитория; не добавляйте его в Git.
4. В консоли диспетчера пакетов Visual Studio выберите проект `DrivingSchool` и выполните `Update-Database -Context DataContext`. Начальная миграция уже есть в проекте; повторно создавать её не нужно.
5. Запустите приложение. Чтобы заполнить пустую базу, добавляйте данные в таком порядке: категории и инструкторы → группы → студенты и занятия → оплаты, экзамены и посещаемость.

Данные проверяются в PostgreSQL (например, через DBeaver). Журнал Serilog создаётся в `Logs/` рядом с исполняемым файлом приложения и не включается в репозиторий.
